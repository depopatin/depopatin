# DepoPatín

Registro y depósito de patines eléctricos. App web instalable (PWA) para móvil y ordenador.

- Registro de entrada: ID del patín, chasis o matrícula, fecha y hora, notas y fotos con la fecha de entrada impresa.
- Buscador por chasis, matrícula, ID y fechas.
- Informe imprimible o en PDF.
